## Capture checklist

1. Use the matching WoW: Forever Beta 1.60.1 client with both GearDuck and
   GearDuck Weights enabled.
2. Use a character and item state that make each intended result easy to
   understand. For the profile image, enable multiple profiles in GearDuck
   options before hovering the item.
3. Move the cursor away from important text and icons. Arrange the tooltip so
   it is not clipped by the screen edge or covered by another window.
4. Use a readable UI scale and capture the full game window at native
   resolution. Prefer PNG; do not add marketing labels, fake numbers, or
   redesign the interface.
5. Keep the game UI authentic, but hide personal chat, account details, guild
   information, or other private content before capture.
6. Review the saved image at full size. Confirm the label, values, item name,
   and any arrows are legible and that the screenshot matches the filename.

## Recommended gallery order

Lead with `01-tooltip-upgrade.png`, then show multiple profiles, settings,
weights, and bag arrows. Add the optional onboarding and edge-case images after
the core features. Keep the CurseForge gallery focused on real in-game addon
screens; do not mix in website, desktop, or mockup images.
