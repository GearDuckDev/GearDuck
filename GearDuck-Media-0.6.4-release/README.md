# GearDuck media kit - 0.6.4-release

This package contains release-ready copy and a capture plan for GearDuck, a
World of Warcraft: Forever addon. It is a publishing/media kit, not the
installable addon archive.

## Package contents

- `CURSEFORGE.md` - description text for the CurseForge project page.
- `RELEASE-NOTES.md` - release announcement text for version 0.6.4-release.
- `docs/SCREENSHOTS.md` - screenshot checklist, capture guidance, and filenames.
- `docs/screenshots/` - place the captured PNGs here using the names in the
  screenshot guide.

The screenshots have not been captured yet. Do not publish the screenshot
gallery until the files listed in `docs/SCREENSHOTS.md` have been added and
checked in the game client.

## Product facts

- Game: WoW: Forever Beta 1.60.1 (`Interface: 16001`).
- Addon: GearDuck, version 0.6.4-release.
- Required companion addon: GearDuck Weights.
- Main features: item Power Level comparisons, editable class/activity
  weights, Questing/Raid/PvP tooltip profiles, onboarding, and bag upgrade
  indicators.

Use the game-client screenshots for the CurseForge gallery. The media kit does
not include screenshots of other addons, mockups, or third-party interfaces.
